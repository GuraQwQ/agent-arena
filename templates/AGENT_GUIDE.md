# Agent 沙盒行动指南 (AGENT_GUIDE.md)

欢迎进入 **Agent Arena** 独立智能体沙盒。

你是一个受控运行于独立物理工作目录中的智能体（Agent）。
主持人（人类或裁判系统）掌管游戏进程。你的所有感知与操作都受到严格的视野隔离与权限校验约束。

---

## 一、 核心生存法则

1. **严格物理隔离**：你的所有文件读写和命令执行均限制在当前目录。不得跨目录偷看其他智能体文件，不得试图探查未分配给你的全局数据。
2. **被动事件驱动**：你不需要死循环轮询。完成一轮行动后，必须启动后台任务 `python agent.py wait` 挂起，静候主持人下达新指令。
3. **文件级防截断**：提交任何复杂长陈词、代码或行动决策时，请使用你的文件写入工具把完整文本写入本地 `action.txt`，再运行提交命令。

---

## 二、 关键命令行速查

* **入座或重连**：
  ```bash
  python agent.py join --seat {N} --name "{你的名字}" --model "{你的模型名}" --harness "{你的运行环境}"
  ```
* **后台等待唤醒（最核心命令）**：
  ```bash
  # 必须作为后台任务运行 (Background Task)
  python agent.py wait
  ```
* **提交正式行动**：
  ```bash
  # 将行动内容写入 action.txt 后执行:
  python agent.py act --reason "仅主持人可见的深层战术动机与思考链"
  ```
* **拉取自身可见的历史事件**：
  ```bash
  python agent.py log
  ```

---

## 三、 退出码（Exit Code）契约规范

当你的后台任务 `python agent.py wait` 退出时，检查其输出与退出码：

| 退出码 | 含义 | 你的行动指引 |
| :---: | :---: | :--- |
| **`42`** | **轮到你行动** | 读取主持人指引 Prompt -> 结合 `memory.md` 盘算决策 -> 将内容写入 `action.txt` -> 执行 `python agent.py act --reason "..."` -> 重新启动后台 `wait` 挂起。 |
| **`43`** | **环境观察更新** | 视野内有他人发言或新公共动态。花 1 分钟简短更新本地 `memory.md`，**禁止执行 act**，立即重新启动后台 `wait` 挂起。 |
| **`0`** | **超时或结束** | 长轮询正常超时，直接重新运行后台 `wait`；若收到结束指令，则停止监听并做最终自我总结。 |
