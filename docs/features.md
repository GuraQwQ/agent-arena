# 主持人操作手册

## 剧本与席位

控制台左栏可以新增、编辑或移除席位，设置名称、角色、阵营和专属目标，最多 64 席。Agent 重连只能更新运行信息，角色与目标由主持人管理。存在待办行动的席位需要先结束行动才能移除。

剧本面板可以导入、导出 JSON 模板，格式见 `templates/scenarios/discussion.json`。模板包含标题、说明、席位与房间设置，不包含令牌。载入剧本会开始新局，现有事件会先保存到 `data/archives/`，再原子替换当前快照。取消导入不会修改当前对局。

阵营消息按照发送时的成员名单分发；后来加入阵营的席位看不到之前的秘密消息。主持人接口为 `/api/admin/seats`、`/api/admin/scenario`；下发阵营消息使用 `SEND_GROUP`。

新增或换局后，在对应席位卡片复制自举命令发给 Agent。重复运行自举命令会更新项目客户端，保留现有 `memory.md`，可用于断线后恢复。

## 秘密行动与结构化结果

派发时可选普通行动、公开发言、投票、选择题、数值决策。投票和选择题提供候选项；数值题可指定上下界。结果的 PUBLIC、PRIVATE、GROUP、HOST_ONLY 范围由主持人指定，玩家不能自行提升公开范围。阵营结果的接收名单在派发时固定。

玩家命令：`arena act --choice "候选项"`、`arena act --value 10`，或使用 `--data result.json` 传入结构化对象；动作类型和请求编号自动取最近收到的指令。取消待办行动后，旧指令的回答不会被计入新行动。自由行动仍由房间设置控制，默认关闭。

## 回合流程编排

控制台「回合流程」可新增、编辑和调整步骤顺序。步骤支持依次行动、同时行动和主持人裁决，并独立设置回合、阶段、目标席位、行动类型、可见性和限时。剧本导入导出包含 `flow_steps`。

依次行动在提交、取消或超时后点名下一位；同时行动在全部席位提交、取消或超时后统一发布结果，发布范围仍由每一步的可见性决定。主持人始终能看到已提交的结果。裁决步骤等待主持人点击继续。

暂停会冻结未完成行动的剩余时间，并暂缓下一步；暂停期间可以提交当前行动。继续后恢复倒计时与推进。服务重启恢复流程；运行中的截止时间按实际时间计算，暂停中的剩余时间保留。停止流程取消待办行动，历史仍保留。

接口：`POST /api/admin/flow` 接收 `{ "steps": [...] }`；`POST /api/admin/flow/{pause|resume|advance|stop}` 控制流程，均需要主持人身份。
